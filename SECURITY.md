# Security Policy

## Supported Versions

| Version | Support Status |
| --- | --- |
| v5.0.0 | Supported |

## Reporting a Vulnerability

If you discover a security issue, report it privately to the project maintainer instead of opening a public issue.

Please include:

- A concise description of the issue
- The affected file or module
- Steps to reproduce
- Any relevant screenshots or sample data

## Response Timeline

- Acknowledgement target: within 2 business days
- Initial assessment target: within 5 business days
- Fix or mitigation target: depends on severity and release impact

## Security Practices

- Preserve browser-local storage compatibility.
- Validate imported data before use.
- Avoid sharing untrusted backup files.
- Keep release metadata and documentation aligned.
- Review documentation and repository changes for accidental data exposure.
