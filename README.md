# SFM PRO Enterprise

SFM PRO Enterprise is a browser-based personal finance application for tracking income, expenses, budgets, loans, credit cards, EMI, investments, reports, settings, backups, and restore operations.

## Release

- Current release: `v5.0 Production Release`
- Status: Production ready
- Storage model: Browser local storage only
- Routing: Static HTML entry points preserved

## Quick Start

1. Open `index.html` in a modern browser, or serve the folder with a static file server.
2. Sign in through `login.html`.
3. Use `dashboard.html` and the pages in `pages/` for daily finance management.
4. Export a backup before clearing browser data or moving to another device.

## Included Areas

- Login
- Dashboard
- Income
- Expense
- Budget
- Loans
- EMI
- Credit Cards
- Investments
- Reports
- Settings
- Backup and Restore
- Search, filters, and charts

- Business logic, calculations, routing, and storage schema are preserved.

- Use a current desktop or mobile browser with JavaScript, local storage, and file APIs enabled.
