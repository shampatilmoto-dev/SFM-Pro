# User Guide

## Getting Started

1. Open `index.html` or the hosted application URL.
2. Sign in from `login.html`.
3. Use the dashboard to review summaries and navigate to modules.

## Core Modules

- Dashboard: overview cards, charts, notifications, goals, calendar, recurring items, backup and restore.
- Income: add, search, filter, and review income entries.
- Expense: add, search, filter, and review expense entries.
- Budget: track budget usage and remaining amounts.
- Loans and EMI: review liabilities and upcoming payment information.
- Credit Cards: review balances and outstanding amounts.
- Investments: track portfolio values and allocation.
- Reports: review financial summaries and exports.
- Settings: manage display preferences and data-related guidance.

## Search and Filters

Use the search boxes and filter controls available on the dashboard and module pages to narrow results without changing stored data.

## Backup and Restore

- Export a backup before making major changes or before moving to another browser/device.
- Keep backups in a safe location.
- Review restore previews carefully before confirming a restore.

## Charts

Charts are rendered from the stored financial data. If a chart has no data, the application shows an empty state instead of failing.

## Settings

Settings are local preferences only. They do not change the underlying financial calculations or data schema.
