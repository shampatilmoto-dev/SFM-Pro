# User Guide

## Overview

SFM PRO Enterprise is a local personal-finance workspace for recording financial activity, reviewing summaries, and protecting data with backups.

## Getting Started

1. Open `index.html` or the hosted application.
2. Sign in from `login.html`.
3. Use the dashboard to navigate to modules.
4. Review summaries before editing or exporting data.

## Core Modules

| Module | Purpose |
| --- | --- |
| Dashboard | Financial overview, cards, charts, insights, notifications, and backup tools |
| Income | Record earnings |
| Expense | Track spending |
| Budget | Review budget usage |
| Loans | Track liabilities |
| EMI | Manage installment schedules |
| Credit Cards | Track card balances and due dates |
| Investments | Review portfolio values |
| Reports | Analyze totals and trends |
| Settings | Manage local preferences |

## Backup and Restore

1. Export a backup before device changes or browser maintenance.
2. Store the JSON file in a secure location.
3. Use the restore preview before confirming an import.

## Search and Filters

- Use search fields to locate records quickly.
- Use filters to narrow module data by type or category.
- Keep dates and categories consistent for better results.

## Tips

- Record transactions promptly.
- Keep names and categories consistent.
- Review dashboard summaries regularly.
- Use backups before major changes.
