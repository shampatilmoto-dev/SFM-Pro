# Code of Conduct

## Our Commitment

SFM PRO Enterprise welcomes respectful, constructive collaboration. We expect everyone participating in the project to help maintain a professional and inclusive environment.

## Expected Behavior

- Be respectful and considerate.
- Focus feedback on the work, not the person.
- Share useful context when reporting issues.
- Keep discussions relevant and professional.

## Unacceptable Behavior

- Harassment, discrimination, or personal attacks.
- Disruptive or abusive language.
- Deliberately misleading technical claims.
- Repeated trolling, intimidation, or bad-faith behavior.

## Enforcement

Project maintainers may remove content, restrict participation, or take other corrective action when behavior violates this code of conduct.

## Reporting

If you need to report a conduct concern, open a private security or maintainer contact channel provided by the project owner and include:

- A description of the issue
- The relevant context or screenshots
- The impact on the project or community

## Scope

This code of conduct applies to repository issues, pull requests, documentation, and any project-related discussion.
