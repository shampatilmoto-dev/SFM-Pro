# SFM PRO AI Development Manual

## Purpose

Define the boundaries, inputs, and review expectations for AI-assisted work on SFM PRO Enterprise.

## Description

AI-assisted work must use approved project metadata, preserve existing business rules, and keep implementation changes traceable. AI may propose changes, create documentation, and prepare templates, but human review remains the approval point for runtime, data, security, Firebase, and financial-workflow changes.

## Future Usage

This manual will guide metadata-driven development, import-template preparation, automated documentation checks, and controlled implementation planning.
