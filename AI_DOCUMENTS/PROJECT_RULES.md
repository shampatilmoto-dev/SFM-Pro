# SFM PRO Enterprise - Project Rules

## 1. General Rules

- Build one feature at a time.
- Never break existing functionality.
- Test every feature before moving to the next.
- Keep code simple and readable.

---

## 2. Folder Rules

components/
Reusable UI components

pages/
Application pages

js/core/
Application bootstrap

js/modules/
Business modules

js/services/
Business services

js/engine/
Calculation engine

css/
Stylesheets

assets/
Images and icons

AI_DOCUMENTS/
Project documentation

---

## 3. Coding Standards

- Use camelCase for variables.
- Use PascalCase for classes.
- Use meaningful function names.
- Avoid duplicate code.
- Keep functions under 50 lines where practical.

---

## 4. UI Standards

- Responsive design
- Dark theme
- Mobile friendly
- Consistent spacing
- Reusable components

---

## 5. AI Rules

Before generating code:

1. Explain the plan.
2. List files to modify.
3. Generate code.
4. Explain testing steps.

Never modify unrelated files.

---

## 6. Git Rules

Commit after every completed module.

Example:

Dashboard Complete

Expense Module

Income Module

Loan Module

---

## 7. Project Goal

Build a professional enterprise-level personal finance management system using HTML, CSS, JavaScript, and Firebase.
